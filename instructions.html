Anything.ai

A local-first AI chat: it runs on your own PC via Ollama, not someone else's server. Two models, real accounts, cross-device sync.

1. Install Ollama

Ollama runs the AI models on your machine. If the app told you it can't find Ollama, install it here:

ollama.com/download

After installing, the two models this app uses (Koda and Soi) need to exist in your local Ollama — ask whoever set this up for you for the model files, or see the project's README if you're setting this up yourself.

2. Using this site instead of localhost

Ollama only trusts requests from localhost by default. Since this site runs on the internet (not your own machine), Ollama blocks it unless you explicitly allow it. If you see "Can't reach Ollama":

  1. Open PowerShell (press the Windows key, type PowerShell, hit Enter)
  2. Paste this and press Enter (replace the URL if this site's address is different): 
    setx OLLAMA_ORIGINS "https://anything-ai-hq.github.io"
  3. Fully quit Ollama — right-click its icon near the clock (bottom-right of your screen) → Quit
  4. Reopen Ollama and wait ~10 seconds
  5. Reload the chat page
If you use both this site and a locally-hosted copy (e.g. localhost:8000), separate multiple allowed addresses with commas: setx OLLAMA_ORIGINS "https://anything-ai-hq.github.io,http://localhost:8000"

3. Signing in

Type your email and click Send magic link — no password. Check your inbox (and spam folder) for a sign-in link, click it, and you're in. Your chats, settings, and memory are tied to your account and follow you to any device.

4. Picking a model

  • Koda — specialized for Luau/Roblox coding.
  • Soi — a general everyday assistant for anything else.

Switch between them using the pill next to the Send button — it applies to the current chat and can be changed mid-conversation.

5. Effort

The other pill next to Send controls how much the model "tries": Low is fast and brief, High is slower and more thorough. There's no separate reasoning mode under the hood — this adjusts response length, randomness, and how carefully it's told to think.

6. Agent Mode

Agents are custom personas — a name plus a description of how it should behave (e.g. "a terse combat-system specialist"). Pick one from the sidebar dropdown before starting a new chat, or create your own under Agent Mode. Agents only change how the model talks; they can't access files or run commands.

7. Slash commands

Type these directly into the chat box:

  • /help — list all commands
  • /explain <code> — explain what some code does
  • /fix <code> — find and fix bugs in some code
  • /remember <fact> — save something for the AI to recall in future chats
  • /forget <keyword|all> — remove remembered fact(s)
  • /memory — see everything currently remembered

8. Settings

Click Settings to set your display name (used in greetings) and how the AI talks: enthusiasm, emoji use, and sarcasm, each Low/Medium/High.

Troubleshooting

  • "Can't reach Ollama" — see step 2 above.
  • No magic link email arrives — check spam. If it still doesn't show up after a few minutes, wait a bit and request a new one.
  • Model gives a weird or wrong answer — these are small, locally-run models. They're not as capable as large cloud AI systems, especially on obscure APIs or complex reasoning.
