Update 1 — Initial release September 2026

Anything.ai launches: a local-first AI chat with two purpose-built models, real accounts, and a full liquid-glass redesign.

Two models

  • Koda — a Luau/Roblox coding specialist, fine-tuned on real open-source Roblox codebases.
  • Soi — a general everyday assistant for anything else.
  • Switch between them per chat with the pill next to Send, mid-conversation if you want.

Real accounts, not just a browser tab

  • Email magic-link sign-in — no password.
  • Chats, settings, memory, and custom agents sync across every device you sign into.

A chat that actually helps

  • Multiple chats with a searchable sidebar history.
  • Agent Mode — save custom personas (a name + a description of how they should behave) and pin them to a chat.
  • Cross-chat memory — the model can remember durable facts about you or your project between separate conversations.
  • Slash commands: /explain, /fix, /remember, /forget, /memory, /help.
  • Effort control (Low/Medium/High) — trade speed for thoroughness per message.
  • Stop generation mid-response, with whatever streamed in kept.
  • Code blocks render with syntax-friendly formatting and a one-click Copy button.
  • Mobile-friendly: collapsible sidebar drawer, no accidental zoom on typing.

Local-first, on purpose

  • Both models run on your own PC via Ollama — not a cloud server you don't control.
  • Built-in detection if Ollama isn't reachable, with exact setup steps.

A real visual identity

  • Full redesign around custom liquid-chrome/mercury artwork — logo, favicons, and distinct avatars for Koda and Soi that appear right in the chat log next to their replies.
  • Frosted glass panels, ambient background motion, and a legacy-interface toggle in Settings if you ever want the older look back.
